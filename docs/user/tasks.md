# Tasks

**Tasks** keeps a to-do list with due dates and priorities. You can add a task by
typing it in, or create one from a message. A **My Day** view shows what is due today.
Open it from **Tasks** in the sidebar.

![The Tasks screen: lists on the left, the add-a-task field and five tasks in the middle, and the convert fields below them.](/screenshots/user-features/tasks-screen.webp){.mw-shot}

## Lists and views

The left pane holds the views and your task lists.

![The list pane of the Tasks screen with markers on All tasks, My Day and the Tasks list.](/screenshots/user-features/tasks-lists.webp){.mw-crop}

1. **All tasks** shows the tasks of every list, finished ones included.
2. **My Day** shows the tasks that are due today or overdue, tasks whose start date is
   today or earlier, and tasks you have put in My Day. Finished tasks are left out.
   When nothing qualifies it says "Nothing due today. Enjoy the quiet."
3. A list, here **Tasks**, shows only its own tasks. The coloured dot is the list's colour.
{.mw-callouts}

Task lists come from your calendar and task account. This screen does not create or
rename lists.

![The My Day view of the Tasks screen, which lists only Approve the print run, the one task due today.](/screenshots/user-features/tasks-myday.webp){.mw-crop}

## Add a task

1. Select a list, or leave **All tasks** selected. A new task goes into the selected
   list, or into the first list when none is selected.
2. Type a title in **Add a task…** and choose **Add**, or press Enter.

   ![The add-a-task row with the title Call the caterer typed in, a marker on the title field and a marker on the Add button.](/screenshots/user-features/tasks-add.webp){.mw-crop}

   1. The title field.
   2. **Add** creates the task.
   {.mw-callouts}

**Add** is unavailable until the lists have loaded.

## Complete, edit or delete a task

Each task is one row.

![One task row, Approve the print run, with markers on its checkbox, its high-priority mark and its Edit button.](/screenshots/user-features/tasks-row.webp){.mw-crop}

1. The checkbox completes the task. A completed task is struck through; tick the box
   again to reopen it.
2. A red **!** marks a high-priority task.
3. **Edit** opens the task for editing. The date is the task's due date, or its start
   date if it has no due date.
{.mw-callouts}

To edit a task, choose **Edit**. You can change the **Title**, the **Due date** and the
**Priority** (**None**, **High**, **Medium** or **Low**), then choose **Save**.
**Cancel** closes the form without saving. Save sends only the fields you changed.

![A task open for editing: Title, Due date and Priority fields with Save, Cancel and Delete buttons.](/screenshots/user-features/tasks-edit.webp){.mw-shot}

To delete a task, choose **Delete** in the edit form. The form asks "Delete this task?
This cannot be undone." Choose **Delete task** to confirm or **Keep task** to cancel.

Right-clicking a task offers the same actions, plus adding it to My Day or removing it
from My Day, and a **Priority** submenu.

If a task is changed on another device while you have it open, the form says so and
keeps your edits. If it is deleted elsewhere, the form closes and tells you.

## Order My Day

In **My Day**, drag a task onto another to put it before that one. The order lasts until you reload the page.

## Create a task from a message or an event

- Right-click a message and choose **Create task from message**. The task is created
  in the selected list, or the first list, and takes the message's subject as its
  title. A notice says "Task created in" the list's name. The task row then has an
  **Open original message** link.
- If you have no task list, the notice says "Create a task list before adding a task
  from this message."
- The **Convert** row under the tasks makes a task from a message or an event when you
  know its identifier. Type the identifier in **message id** and choose
  **Mail → task**, or type it in **event id** and choose **Event → task**. The title
  becomes "Follow up: mail" or "Prep: event" followed by the identifier.

![The Convert row of the Tasks screen with a message id field, a Mail to task button, an event id field and an Event to task button.](/screenshots/user-features/tasks-convert.webp){.mw-crop}

1. **message id** field.
2. **Mail → task**.
3. **event id** field.
4. **Event → task**.
{.mw-callouts}

## Troubleshooting

- **Add is greyed out.** The task lists have not loaded yet.
- **Create task from message does nothing.** The administrator can switch off the tasks
  feature.
