# Notifications

**Notifications** is the list of important account activity: sign-ins, security
changes and app updates. It is an inbox for things you may want to review, not a place
that resolves them. Open it from **Notifications** in the sidebar.

Notifications about new mail on your device are a different thing; they are set under
Notifications in Settings. See [Settings: interface](/user/settings/interface).

![The Notifications screen with its Active, Archived and Dismissed buttons, a search field, a type filter and the message No notifications in this view.](/screenshots/user-features/notifications-screen.webp){.mw-shot}

## Review and organise notifications

![The top of the Notifications screen with markers on the Active, Archived and Dismissed buttons, the search field and the Type menu.](/screenshots/user-features/notifications-filters.webp){.mw-crop}

1. **Active** shows the current notifications. The screen opens in this view.
2. **Archived** shows notifications you archived.
3. **Dismissed** shows notifications you dismissed.
4. **Search** narrows the list by the notification's title, and by the IP address or
   browser it mentions.
5. **Type** narrows the list to one kind: **All types**, **Security**, **Session
   warnings**, **Sign-ins** or **App updates**.
{.mw-callouts}

Each notification shows a title and the time. The titles you can meet are:

- **Successful sign-in**
- **Sign-in from an unrecognized device**
- **Sign-in from a new country**
- **Two-factor authentication changed**
- **Mailbox access was granted**
- **A forwarding rule was added**
- **An API key was created**
- **Account security activity**

Sign-in notifications show details such as the browser and IP address.

Each notification has these buttons:

- **Open related action** goes to the place in Settings where you can look into it:
  the security centre for sign-ins and security changes, the access section for an
  API key, the rules section for a forwarding rule. For an app update the button
  reads **Reload now** and reloads the page.
- **Dismiss** moves it to **Dismissed**.
- **Archive** moves it to **Archived**.
- **Restore** moves an archived or dismissed notification back to **Active**.

::: warning
Dismissing or archiving a notification only tidies the list. It does not change the
security of your account. If you do not recognise a sign-in, use the security centre
in Settings.
:::

To act on several notifications, use the selection button at the left of the
**Active** button, tick notifications, and use the bar that appears.

## Troubleshooting

- **"Notifications could not be loaded or updated. Try refreshing."** The list could
  not be fetched. Choose **Retry** if it is offered, or reload the page.
- **"No notifications in this view."** There is nothing in the tab and filter you chose.
