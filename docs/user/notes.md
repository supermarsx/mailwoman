# Notes

**Notes** keeps short rich-text notes. A note has a title, a body with basic
formatting, an optional colour and tags, and links to messages, events and contacts.
Open it from **Notes** in the sidebar. There is no Save button: every change is
saved as you make it.

![The Notes screen: the note list on the left and the open note Launch evening checklist on the right.](/screenshots/user-features/notes-screen.webp){.mw-shot}

## Find and create notes

![The note list with markers on New note, the search field and the pinned note Launch evening checklist.](/screenshots/user-features/notes-list.webp){.mw-crop}

1. **+ New note** creates a note titled "Untitled note" and opens it.
2. **Search notes…** narrows the list to matching notes as you type.
3. A note in the list shows its title, a snippet of its body and its tags. A pin
   marks a pinned note. Click a note to open it.
{.mw-callouts}

Once any note has a tag, a row of tag buttons appears above the list: **All** and one
button per tag. Choose a tag to show only the notes that carry it, and choose it again
to clear the filter.

Right-click a note for **Open**, **Pin note** (or **Unpin note**), **Duplicate**,
**Copy** and **Delete note**. **Copy** copies the note's text.

## Edit a note

![The top of an open note with markers on the title, the Unpin note button, the Delete note button and the tag field.](/screenshots/user-features/notes-detail.webp){.mw-crop}

1. The title field.
2. **Pin note** / **Unpin note** keeps a note at the top of the list. The button shows
   the state with a pin; here the note is pinned, so it reads **Unpin note**.
3. **Delete note** deletes the note straight away, with no confirmation.
4. The tag field, labelled **+ tag**. Type a tag and press Enter. Tags are stored in
   lower case. Click the cross on a tag to remove it.
{.mw-callouts}

Under the title, the **Note color** control sets a colour for the note. It reads
**Not set** until you choose one; the colour shows as a swatch in the list.

![The formatting toolbar and body of a note, and the Links area below it, with markers on Bold, Bulleted list, Insert link and the link type menu.](/screenshots/user-features/notes-editor.webp){.mw-crop}

1. **Bold**. The toolbar also has **Italic**, **Underline**, **Strikethrough**,
   **Heading**, **Numbered list**, **Quote** and **Clear formatting**.
2. **Bulleted list**.
3. **Insert link** asks for a link address ("Link URL (https://…)").
4. The link type menu of the **Links** area, explained below.
{.mw-callouts}

## Link a note to a message, event or contact

The **Links** area keeps references from a note to other items. Choose a type
(**Message**, **Event** or **Contact**), type the item's identifier in "id to
link…", and choose **Link**. The link appears as a chip under **Links** with a
cross to remove it. A note with no links shows **No links**.

The identifier is entered by hand; there is no picker for messages, events or
contacts.

## Troubleshooting

- **A note changed while it was open.** If the note is changed on another device or
  session, a notice says so. Text you typed is kept, and your next edit saves it.
- **The note you had open was deleted elsewhere.** The editor closes and shows "The
  note you had open was deleted on another device or session."
- **The note could not be created.** The server refused it; try again.
